# 非遗侗绣文化展示网站 · Dong Embroidery Heritage Website

> 一个以「针脚里的侗绣记忆」为主题的非遗数字化展示网站——用现代化的网页呈现侗族刺绣的起源、技艺与成品之美，让传统工艺在互联网上被更多人看见。

## 🔗 在线访问

**https://littlemonster-huang.github.io/fei-yi-dong-xiu/**

（纯静态站点，手机 / 电脑浏览器均可直接访问）

## 📖 项目介绍

本项目是大学创业训练计划项目 **「云丝侗韵·智绣魔方」** 的线上展示阵地，围绕非遗侗绣的数字化传播展开。

网站以"针脚里的侗绣记忆"为叙事主线，通过图文与视频结合的方式，完整呈现侗绣的：

- **起源与来源** —— 侗绣的历史脉络与文化土壤
- **制作技艺详解** —— 从画纸到成针的工艺流程
- **特点与成品展示** —— 代表作品与技艺特色
- **侗绣宣传视频** —— 动态影像记录，直观感受技艺之美

## 🛠 技术要点

- **原生 HTML / CSS / JavaScript**：不依赖任何框架，轻量、加载快、可长期维护
- **响应式布局**：适配手机、平板、电脑多种屏幕尺寸
- **本地字体加载**：字体资源随站点本地化，无外部依赖，国内访问稳定友好
- **相对路径资源组织**：全站资源统一相对路径引用，站点可整体迁移、不断链
- **原生 JS 交互**：章节导航、视频播放控制、平滑滚动等交互均由原生脚本实现
- **视觉资产管理**：基于 Pixso 完成整站视觉设计与数字资产输出，并统一接入网页
